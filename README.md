
# DIGISMART
### Cerdas dan Aman di Dunia Digital

## Deskripsi
DIGISMART merupakan website edukasi yang bertujuan
meningkatkan literasi digital masyarakat.

Website ini membantu pengguna memahami cara
menggunakan teknologi secara cerdas, aman,
dan bertanggung jawab.

## Fitur
- Beranda
- Login dan Register
- Dashboard Pengguna
- Materi Literasi Digital
- Edukasi Anti-Hoaks
- Keamanan Digital
- Jejak Digital
- Literasi AI
- Kuis Interaktif
- Sistem Penilaian

## Teknologi
- HTML5
- CSS3
- JavaScript
- LocalStorage
- SessionStorage

## Struktur File
- index.html : Struktur website
- style.css : Desain dan tampilan
- script.js : Fungsi dan interaksi
- README.md : Dokumentasi proyek

## Cara Menjalankan
1. Buka Visual Studio Code.
2. Buat folder DIGISMART.
3. Masukkan seluruh file ke dalam folder.
4. Instal ekstensi Live Server.
5. Buka index.html.
6. Klik kanan dan pilih Open with Live Server.

## Tujuan
Meningkatkan pengetahuan dan kesadaran
masyarakat dalam menggunakan teknologi digital.
